## Constraints (from PRD v2.0)

- Modern, trustworthy, uncluttered; primary palette indigo/deep blue + white space, "professional + clean" (see `PRD.md` §UX).
- Light/dark themes, fully keyboard-operable, WCAG 2.1 AA.
- Any tool completes in ≤ 3 steps (drop → do → download).
